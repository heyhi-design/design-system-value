Three contact sheets referenced by `docs/how-value-gets-shown-to-leadership.md`:

| File | Contents |
|---|---|

| `sheet-B-inhouse-dashboards.jpg` | In-house adoption dashboards |

The survey refers to them as contact sheet A, B, and C; this table is the only place the letters map to filenames. Each is a set of crops of public web pages, captured for study and comparison. They are **not for redistribution outside this repository**: the underlying pages belong to the organizations that published them, and the crops are held here only as evidence for the survey's pattern matrix.

A public release of this repository must drop these three files or replace them with material the publisher has the right to distribute, update the survey's references accordingly, and regenerate the manifest (`bash scripts/manifest.sh --write`), since `MANIFEST.txt` lists them. Nothing else depends on them; the survey's text and pattern matrix stand on their own with the source URLs in `kit/SOURCES.md`.
